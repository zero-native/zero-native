# @zeronative/ui

The components of [zero-native](https://github.com/zero-native/zero-native), with React Native's names: `View`,
`Text`, `Image`, `Pressable`, `TextInput`, `ScrollView`, `FlatList`, `Modal`, `Svg` and more. The compiler turns
them into native Compose and SwiftUI / UIKit views; nothing of this package runs on the phone.

What is the same as React Native, renamed, different or missing:
[docs/rn-compatibility.md](https://github.com/zero-native/zero-native/blob/main/docs/rn-compatibility.md). Apache-2.0.
