# Fonts in the sample app

The files in `assets/fonts/` are there to test `fontFamily` (RN gaps lab). All are under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them in an app:

| File | Font | Source |
|---|---|---|
| `Inconsolata-Regular.ttf`, `Inconsolata-Medium.ttf`, `Inconsolata-SemiBold.ttf` | Inconsolata (Raph Levien and contributors) | Google Fonts |
| `SpaceMono-Regular.ttf` | Space Mono (Colophon Foundry) | Google Fonts |
| `lato-black.ttf` | Lato Black (Łukasz Dziedzic) | Google Fonts |
