# Loaders from svg-spinners

Six animated SVGs from [n3r4zzurr0/svg-spinners](https://github.com/n3r4zzurr0/svg-spinners) (MIT, Utkarsh Verma,
see `LICENSE`), used by the SVG lab's Motion section to show that downloaded SMIL / CSS animations play as they are
(`docs/svg.md` §15). The only change: `fill="currentColor"` on each `<svg>`, so `color` can tint them.
